## 五、硬边界速查（不可擅自推翻）

1. **"潜意识"不是组件**——只作灵感，禁止进入组件命名、因果解释、评估指标。
2. **对主 AI 只暴露两个原语**：`memory`（forget/revise/remind/link/unlink）与 `change`（L1/L2 大改申请）。其余零工具。
3. **旁路只建议，代码服务才执行**。旁路失败 → 降级为无记忆；代码服务失败 → 熔断。
4. **遗忘不含删除**。手段仅限抑制/降权/隔离/脱敏/压缩；归档存原始对话归类，不做摘要重写。
5. **L0 编译进代码**，不进存储——一旦可写，只读承诺即失效。
6. **审批者信息隔离**：不看对话原文，只看结构化反思 + L0/L1 锚点 + 历史改动链 + 来源可信度。
7. **长短不是存储分家，是注入分流**：一个 `MemoryEntry`，`short` 直接注入，`long` 必须由旁路裁决。
8. **注入是双向的**：上行看"相不相关"，下行看"有没有被用"；**"写进去"本身绝不提升权重**，否则系统会奖励自己多写。

> 第 8 条是 2026-10-26 落地反馈环时才真正兑现的（`injection_log` 只记账，`USED` 才涨）。
