## 二、各期核心内容与遗留边界

### M0 补短板 ✅
- **召回排序**：乘积 `relevance × salience × trust`（已移除 `recency`，候选均带日期交由旁路判读，避免重复计权）。
- **遗忘状态**：`active` / `merged` / `superseded` / `suppressed` + `replaced_by`；默认检索带 `superseded`，`merged` 不再自动出。
- **反馈环**：注入仅写 `injection_log`，只有维护旁路判 `USED` 后才推进 `use_count` 与权重；默认启用 `salience.ts` 绝对分评分模型（`AS_SALIENCE=0` 可退回 `decay()`）。

### M1 遗忘五区 🟡
- **已闭环**：按轮压缩与 `toolCall` 配对保护（`turns.ts`）、不可移出区绝对优先权、三条路径同源「已移出可恢复」信号（`recover.ts`）、R2–R5 补救链、70/85/95% 三档策略、写侧与注入前二次脱敏。
- **仍缺（主要缺口）**：**索引区/索引化**——线索 / 实体 / 时间三类索引（方案见 [`records/38`](records/38-indexing-design.md)，已抽时间解析器 [`facet.ts`](../pi/src/facet.ts)，暂缓于世界树重构期间），以及**世界树 P-d 起**的改造（见 [`09-world-tree.md`](09-world-tree.md) §11）。
- **未补历史测试**：M1.2 原设计的“人为构造含承诺与已解决分支的长对话，压缩后承诺仍在”专项场景尚未构造跑通（当前由折叠与保护轮单测替代覆盖）。

### M2 交涉通道与变更门控 🟡
- **已闭环**：`memory` 单一自然语言交涉工具覆盖五动作；`change` 结构化反思、隔离审批者、双维冷却（时间 ∩ 轮次，人工批准跳过）与 `/as-revoke`。
- **明确取舍**：按 [`02-isolation.md`](02-isolation.md) A7 裁定，**不做静态幅度上限（delta-clamp）与连续同向计数升级线**——风险由旁路结合历史链评估，后果由代码映射。

### M3 归档检索 ✅
- 六层粒度钳制（`所有 → 年 → 月 → 周 → 天 → 时`），任一层命中 ≤3 段直接给片段；会话备注与时间下钻并列；`archive(q)` 仅检索指针表摘要（≤3 条 × 300 字，每轮限 2 次）。
- **已知边界**：`archiveRefs` / `searchArchive` 当前只覆盖最近 500 条归档指针，更老归档需后续扩展分页或维护补索引。

### M4 审计成链 ✅
- `audit_chain` 以 `HMAC-SHA256(key, prev|kind|data|at)` 串链，`session_start` 启动校验断点并落 `as/audit_broken`（不阻断对话）。
- **已知边界**：密钥存在同库 `meta` 表，防“静默改历史”不防持有库文件者整链重算。

### M5 分发 🟡
- **已完成**：`package.json` `files` 白名单、`npm pack` 可打独立包并在解包目录独立跑通 22 项测试；`pi` CLI 1.4.0 上验证 `--extension` 加载与用户扩展目录（`scripts/deploy.sh`）自动发现。
- **未完成**：
  1. **Aether 宿主验证**：Aether 当前 README 标注 `pi 0.85.1`，而扩展钩子依赖 `1.x`，待其升级后再测。
  2. **npm 发布**：尚无发布凭据，正式发布前需基于干净 HEAD 重新打包验证。

## 三、待办与开放问题（暂不急于动手）

1. **只读控制台界面**（远期）：利用封存于 `tag frontend-frozen-2026-10-25` 的 UI 体系或基于 `view.ts` 的 JSON 结构扩展只读展示（世界树浏览、审计时间线、单轮压缩前后对比）；不实现 dsh Remote 协议。
2. **世界树的自动归类**：世界树当前“只长不修”（[`09-world-tree.md`](09-world-tree.md)），长期演化需确定：由写入方顺手报重还是维护旁路统一扫、怎么判定语义重复、发现后直接 `MERGE_TAG` 还是列待裁。
3. **跨库 / 多 profile 编排**：先补齐 [`records/47`](records/47-profile-orchestration.md) 建议的只读枚举 `profiles/`、展示名对齐与误拼报错，跨库审计身份确认后再评估运行中切库。

## 四、明确不做

- **iOS 本地运行**：iSH 模拟与 JIT/二进制限制代价过高，见 [`05-platform.md`](05-platform.md)。
- **自建聊天 UI**：宿主提供对话与运行时；封存前端只作参考或远期只读控制台素材。
- **本地大模型推理 / 设备自动化**：旁路一律调远端 API，不操作手机系统与屏幕。
