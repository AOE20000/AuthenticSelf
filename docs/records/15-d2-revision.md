# 实测记录 15：D2 修订（只读检索不算原语）

> 阶段实测记录（当前状态以 [`08-completeness.md`](../08-completeness.md) 为准）。

`archive` 加进来时撞上 D2 的"此外零工具"。裁定是**改 D2**，把判定标准写成一句可执行的：

> **原语 = 能改变记忆或身份的工具。只读工具不计入。**

理由："零工具"的本意是"不让模型通过大量接口改变自己"，不是"不让它看见东西"；
而 `source` §7.3 本来就要求模型自己按分阶段纪律下钻归档。

只读工具的三条约束（防它长成第二个写口子）——**现在三条都兑现了**：

| 约束 | 实现 |
|---|---|
| 只读 | 不写库、不改锚点、不改状态 |
| 粒度受钳制 | `source` §7.2 六层 |
| 留审计 | `as/archive_query { key, refs }`，实测有记录 |

副作用观察：`archive` 不带 key 时，若归档只有 2 段，直接返回片段而非年份清单——
≤3 规则在"所有"层同样生效，这正是 §7.3 的"不机械下钻"。
